# T3 Just

SaaS de gestão para pequenos escritórios de advocacia: do primeiro atendimento ao honorário recebido, sem perder o controle do trabalho.

O projeto está na fase de descoberta. Ainda não há código do sistema. Este repositório reúne a pesquisa, as decisões e o protótipo usado para validar a ideia.

## Como abrir o protótipo

Baixe o repositório e abra `prototipo/index.html` no navegador. Os dados são inventados.

As respostas ficam salvas no navegador de quem responde. Na última página dá para enviar pelo WhatsApp ou copiar o texto. O botão "Salvar arquivo (JSON)" só aparece na versão publicada no Claude.

## Situação

- Público hipotético: escritórios de 3 a 10 pessoas, com o sócio centralizando a gestão.
- Uma advogada parceira acompanha o desenvolvimento e vai responder o protótipo.
- Sem orçamento, prazo, preço ou tecnologia definidos.
